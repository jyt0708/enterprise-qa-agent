# 测试预期、实际结果、失败和限制

| 用例 | 输入或设置 | 主要通过条件 |
|------|-----------|-------------|
| T01 明确答案 | “年假要提前多久申请？” | 回答 3 个工作日，引用 D03 |
| T02 文档冲突 | “报销期限多久？” | 引用 D01、D02，查证后不擅自选择，应列出冲突与引用，并请求确认 |
| T03 资料外问题 | “公司今年年终奖发几个月？” | 不编造数值，说明资料不足 |
| T04 相似问题改写 | “想休年假，最晚什么时候提申请？” | 与 T01 的问题核心一致 |
| T05 上下文追问 | 年假问题后问“那谁来审批？” | 理解指代，读取并引用 D04 |
| T06 文档内容替换 | 将 D03 的 3 个工作日改为 5 个工作日 | 答案和引用随原文改变 |
| T07 冲突消除 | 移除 D02，再问报销期限 | 依据 D01 回答 30 天 |
| T08 工具失败 | 首次读取失败，之后可恢复 | 模型观察错误后决定下一步，恢复后正确回答 |
| T09 持续失败或上限 | 工具持续失败，或低预算运行 | 返回 `tool_error` 或 `incomplete` |
